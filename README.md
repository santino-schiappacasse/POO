# 72.33 Programación Orientada a Objetos
## Guías de ejercicios de Ruby

### Contenido

- `guias/` Fuentes de las guías de ejercicios
- `lib/` Biblioteca `POO::SortedSet` utilizada por algunos ejercicios

### TP's

- **TP N°8: Introducción a Ruby**
- **TP N°9: Colecciones en Ruby**
- **TP N°10: Diseño Avanzado en Ruby**

### Requisitos

#### Opción 1: DevContainer (recomendado)

Se necesita Docker instalado.

En VSCode/RubyMine, abrir el proyecto en contenedor.

#### Opción 2: Ejecución local

Se necesita Ruby 4 instalado.

### Modo de uso

Resolver los ejercicios dentro de la carpeta correspondiente en `guias/`.

Por ejemplo:

```bash
cd guias/tp8/ej1
ruby ej1.rb
```
